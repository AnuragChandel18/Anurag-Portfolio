# Anurag Chandel — Developer Portfolio

A responsive, static personal portfolio built with HTML, CSS and JavaScript. It uses no external libraries or build step, so it can be hosted directly on GitHub Pages.

## Live Demo

**Portfolio website:** [Visit Anurag Chandel’s Portfolio](https://anuragchandel18.github.io/portfolio/)

> This link is the intended GitHub Pages URL. It will start working after this repository is uploaded to GitHub and GitHub Pages deployment is enabled.

## Deploy to GitHub Pages

1. Create a public GitHub repository named `portfolio`.
2. Upload **all files and folders inside this directory** to the repository root (not the parent folder).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After GitHub finishes publishing, the site should be available at `https://AnuragChandel18.github.io/portfolio/`.

The repo name and account username determine the Pages URL. If you choose a different repository name, update the URL you share.
